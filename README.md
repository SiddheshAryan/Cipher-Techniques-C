# Cipher Techniques in C

## 📌 Overview

This project implements three classical cryptographic techniques in C language:

1. Hill Cipher
2. Playfair Cipher
3. Polyalphabetic Cipher (Vigenère Cipher)

The programs are implemented with consideration for boundary conditions and test cases involving spaces, digits, and special characters.

## 🎯 Objectives

- Implement classical encryption techniques using C.
- Understand the working principles of different substitution and matrix-based ciphers.
- Handle spaces, digits, and special characters correctly.
- Test the implementations using different plaintext inputs and boundary cases.
